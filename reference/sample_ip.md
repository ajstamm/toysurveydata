# Create fictional IP addresses

Create fictional IP addresses

## Usage

``` r
sample_ip(count)
```

## Arguments

- count:

  integer; number of responses

## Examples

``` r
sample_ip(count = 5)
#>   id      ip_address
#> 1  1  151.110.200.78
#> 2  2   204.46.196.76
#> 3  3    63.158.4.129
#> 4  4 229.195.254.189
#> 5  5   102.229.23.54
```
